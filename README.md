# Attendance Tracker

A simple browser-based attendance tracker to add, view, and delete student attendance records.

## Features

- Add student name, date, and attendance status
- View total, present, and absent counts
- Delete individual records or clear all records
- Saves records in the browser using local storage

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

Open `index.html` in any web browser.
